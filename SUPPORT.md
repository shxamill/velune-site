# Support

## Getting help

- For a reproducible defect, open a Bug report using the issue form.
- For a proposed improvement, open a Feature request.
- For usage questions, include the Node.js version, operating system, command, and exact error message.

## Before opening an issue

Check the README and existing issues. Include steps to reproduce and, for visual problems, a screenshot and viewport size.

## Sensitive information

Never include passwords, API keys, access tokens, private client information, or unredacted logs in public issues. Use the private process in SECURITY.md for security concerns.

This is an independently maintained project; support is provided on a best-effort basis.
