# Security Policy

## Reporting a vulnerability

Do not publish exploit details, credentials, personal data, or an unpatched vulnerability in a public issue or pull request.

Use the repository's **Security** tab and select **Report a vulnerability** to submit a private report when that feature is available. If private vulnerability reporting is unavailable, contact the maintainer privately through https://github.com/shxamill.

Include the affected component, impact, reproduction steps, and any suggested mitigation. Redact secrets and personal information.

## Scope

This is an independently maintained website. Security fixes and response times are not guaranteed. Please allow the maintainer a reasonable opportunity to investigate before making a report public.
